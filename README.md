# Validation Copilot — AI-OS

> An AI agent that helps startup founders validate ideas before they spend months and money building the wrong thing.

## What It Does

1. **Startup Intake** — Extracts domain, customer, stage, business model from free text
2. **Assumption Mapping** — Risk-ranked map of what the idea depends on (desirability / viability / feasibility)
3. **Market Research** — Grounded web research, every claim cited or marked "insufficient evidence"
4. **Experiment Design** — Cheapest test for the riskiest assumption; bias validator rejects leading questions
5. **Primary Evidence Analysis** — Analyzes real interview notes / CSV uploads with commitment ladder classification
6. **Decision Memo** — Go / Iterate / Stop / Test More verdict with confidence level and next experiment

## Architecture

```
User Input → Router (Groq) → Planner (Gemini) → Executor → Verifier (Gemini) → Output + Trace
```

**Key safety properties:**
- Verifier strips unsupported claims before they reach the user
- Leading-question validator blocks biased survey questions
- `stats` tool computes all numbers deterministically — never by the model
- Hard rule: cannot output "Go" without rung-4+ x3 sources, n≥30 (or n≥12 saturated interviews)

## Quick Start

### 1. Install dependencies
```bash
cd apps/web
npm install
```

### 2. Set up environment
```bash
cp .env.example .env.local
# Fill in: GEMINI_API_KEY, GROQ_API_KEY, SUPABASE_URL, SUPABASE_ANON_KEY
```

### 3. Set up database
Run `packages/db/schema.sql` in your Supabase SQL Editor.

### 4. Run dev server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Key Design Decisions

### Anti-Hallucination
- All market/competitor claims use Gemini's `google_search` grounding tool
- A separate Verifier model call checks every output against retrieved sources
- Math is computed in code (`stats` tool), never generated by the model

### Evidence Quality Enforcement
The commitment ladder (opinion → intent → time given → contact shared → commitment) is enforced in code:
```typescript
// Hard rule — cannot be bypassed by prompt
if (verdict === "go" && !allowGo) {
  verdict = "test_more"; // override
}
```

### Compliance (Egypt PDPL)
- `leads` table requires explicit `consent_given=true` + timestamp + exact consent text
- No WhatsApp outreach (P2 — needs marketing license)
- Acceptable sources: founder-owned lists, sign-up forms with consent checkbox
